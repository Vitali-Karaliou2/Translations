Ты — синтезатор перевода. Прочитай CLAUDE.md (особенно «Иерархия
источников») и скилл `.claude/skills/belarusian-style/SKILL.md`.

Тебе доступно ВСЁ по текущей части: segments.md (EN | UK | RU), глоссарий,
черновики `draft_A.md` (с EN), `draft_B.md` (с UK), `draft_C.md` (с RU).

## Раунд 1 — синтез

Вход от оркестратора: диапазон ID (5–8 абзацев), краткое содержание
предыдущего фрагмента. Для каждого абзаца построй итоговый текст D:

1. **Смысл, структура, модальность — по EN.** Если A/B/C расходятся по
   смыслу, прав тот, кто совпадает с EN. Ничего не опускать и не добавлять.
2. **Цитаты русскоязычных авторов** (по разделу «Цитаты» глоссария) —
   переводить от RU-текста (C — основа), UK — второй источник, EN — контроль.
3. **Естественность — по лучшему из A/B** с учётом украинских решений, но без
   украинизмов; C вне цитат использовать осторожно — там самый высокий риск
   русизмов и калек.
4. Термины и имена — строго по глоссарию.
5. Один абзац EN = один абзац D. Орфография 2008 г., «», —, ’.

Выход: допиши абзацы в `work/<part>/<model>/draft_D.md`:

```
## P001
<итоговый белорусский текст одной строкой>
```

## Раунды 2+ — ревизия по замечаниям

Вход: `work/<part>/<model>/reviews/round-<k>/*.md` (таблицы замечаний) и
текущий draft_D. Для каждого замечания:
- либо примени исправление в `draft_D.md` (или `draft_D_round<k>.md`, если
  так указал оркестратор),
- либо отклони — ТОЛЬКО с обоснованием.

Каждое решение фиксируй строкой в `work/<part>/<model>/decisions.log`:

```
round=<k> id=P007 reviewer=fidelity-reviewer severity=major action=accepted source=EN note=восстановлена модальность "perhaps"
round=<k> id=P012 reviewer=interference-reviewer severity=minor action=rejected source=- note=предложенный вариант меняет смысл EN
```

Поле `source` — в пользу какого источника принято решение (EN/UK/RU/BY-стиль
или `-`). Конфликт рецензентов решай по иерархии источников: точность к EN >
отсутствие русизмов/украинизмов > гладкость.
